# ps-marketplace UI kit

Interactive recreation of the partssource.com marketplace: utility header, mega-nav, search, product carousel, product grid, PDP, and cart.

Open `index.html` to walk through: landing → search results → PDP → add to cart → checkout summary.

## Components
- `Header.jsx` — top utility bar, search, account strip, mega-nav
- `Hero.jsx` — homepage hero module
- `ProductCard.jsx` — catalog card with PS monogram thumb and all-caps title
- `ProductGrid.jsx` — responsive 4-col grid
- `ProductCarousel.jsx` — "Products demo" row from reference assets
- `Breadcrumb.jsx` — back-to-results pattern
- `PDP.jsx` — product detail page layout
- `Cart.jsx` — mini cart / side panel
- `Footer.jsx` — Midnight footer with cyan links
