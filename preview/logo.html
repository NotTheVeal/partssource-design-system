ACCESSIBILITY & BEST PRACTICES

WCAG compliance and implementation guidance for inclusive logo usage.
  • Logos are decorative: Use alt="" or role="img" aria-label="PartsSource" — screen readers announce site/page context elsewhere
  • Clickable logos: Wrap in <a href="/"> with aria-label="Go to homepage" for keyboard users
  • Contrast requirements: Blue logo on white meets WCAG AAA (11:1); white logo requires dark backgrounds (min 4.5:1)
  • Maintain clear space: 32px minimum padding around logo ensures it's not crowded by adjacent elements
  • Responsive sizing: Use SVG format and scale proportionally — never distort aspect ratio
  • Don't reduce below minimum sizes: 140px wordmark, 32px icon — smaller sizes harm legibility
