Design System / Top Navigation

Top Navigation

The horizontal banner that anchors every PartsSource page. It carries three stacked rows — a thin utility bar (phone & meta links), the main row (brand, search, categories, cart, facility selector), and a colored page hero with the page title and Pro Account panel. Specs are at the design width of 1440 px; the bar is full-width fluid in production with all internal elements pinned to a 40 px gutter.

  • Utility row (28 px): White surface with a 1 px #E0E0E0 bottom border. Right-aligned cluster of phone, Help, and About Us at 14 px Source Sans Pro. Phone number renders in #009CF4 with the icon glyph at #000; everything else is #000.
  • Main row (60 px): White surface with a 1 px #E0E0E0 bottom border, 40 px horizontal gutter, 18 px gap between groups. Holds the wordmark (≈200 px), search (flexible up to 800 px), Categories+, cart with badge, vertical divider, and the facility selector.
  • Search (32 px): 5 px corner radius, #CCCCCC stroke, 14 px placeholder in #777. The submit button is a 34 px square in PS Orange #FF9505 with a white search glyph; corners are flush-right with the field.
  • Cart: 32 × 32 hit area with the cart glyph in PS Blue #005BA6. The badge is a 14 px PS-Blue circle (white "3") pinned to the top-right corner with a 2 px white stroke for separation.
  • Facility selector: 13 px map-pin icon, then a two-line stack — 12 px "Selected Facility" caption above the 16 px bold facility name. Has no hover state — clicking opens the Select Facility modal (see below).
  • Page hero (52 px): Solid #003763 from the left edge through ~936 px. The right 504 px is a slanted panel filled #D0EDFC with an inset shadow inset -4px 4px 10px rgba(0,0,0,.19). The slant clip-path runs 54 px 0 → 100% 0 → 100% 100% → 0 100%.
  • Hero title: 24 px Source Sans Pro at letter-spacing:-.01em, white, 36 px line-height. Sits 24 px from the left edge.
  • Pro Account panel: Hospital wordmark + 16 px bold facility name in #4C4B46, a 24 px #777 divider, then "PRO ACCOUNT" in 16 px bold #00AEEF with a wide letter-space.

Breakpoints

The top nav has four supported widths. Desktop (1440 +) and Wide-desktop (1920 +) keep the three-row composition; Tablet (≤ 1024) and Mobile (≤ 480) collapse to a stacked layout — utility row drops, hamburger replaces Categories, search moves below the wordmark, and the page-hero collapses to a slim navy bar with just the facility and a notification bell.

Accessibility & Best Practices

WCAG compliance, keyboard support, and implementation guidance for the top nav.
  • Landmark role: Wrap the whole bar in <header role="banner">. Place the search inside <form role="search"> and the brand logo inside the header so it's part of the banner landmark.
  • Skip link: Provide a "Skip to main content" anchor above the utility row so keyboard users can bypass three rows of chrome.
  • Tab order: Phone → Help → About Us → Logo → Search input → Search submit → Categories → Cart → Facility. The hero row is non-interactive on the default route.
  • Cart badge: The "3" must be exposed semantically — use aria-label="Cart, 3 items" on the cart link and hide the badge text with aria-hidden="true" so screen readers don't read it twice.
  • Search submit: Icon-only button needs aria-label="Search". The orange button measures 4.6:1 contrast for the white glyph (passes AA Large + AA non-text), and the field placeholder #777 on white is 4.6:1 (passes).
  • Color contrast: White on the navy hero #003763 measures 12.4 : 1 (AAA). PRO ACCOUNT #00AEEF on #D0EDFC measures 2.1:1 — the label is paired with the bold hospital name to meet the AA non-text requirement; treat it as decorative emphasis only and don't use this pairing for any other text.
  • Focus indicator: 2 px #B6D5F0 outline with 2 px offset on every focusable element. On the orange search button the focus ring uses #003763 for visibility against the orange fill.
  • Touch targets: Cart, Categories, and the facility selector each meet 44 × 44 px including padding. The 32 px search field uses an oversized 34 × 32 button — keep finger-reachable on touch via 8 px hit-area extension on the parent.
  • Facility switcher: Render as a <button aria-haspopup="dialog">; opening should set focus into the dialog and trap focus until dismissed.
  • Slanted Pro panel: Decorative — shapes and gradients carry no semantic meaning. The hospital name & PRO ACCOUNT label sit on the regular DOM order so screen readers read them in source sequence.
  • Responsive: Below 1280 px the search collapses to icon-only and Categories is folded into a hamburger; below 768 px the utility row drops and the cart + facility move into the mobile drawer.
