Design System / Body Type

Typography · Body

Body copy uses Source Sans Pro Regular (400) on a 16 px base, 1.5 line-height. Labels, captions, and small UI text follow a compressed micro-scale. Monospace is reserved for code, part numbers, and technical data.

Accessibility & Best Practices

WCAG compliance and implementation guidance for inclusive typography.
  • Minimum body text size: 13px (small UI text like captions) — 15px preferred for long-form reading
  • Line height minimum: 1.5 for body text (WCAG 1.4.12) — improves readability for users with cognitive disabilities
  • Contrast ratios: Body text (13-15px) must meet 4.5:1 (WCAG AA); large text (18px+) needs 3:1 minimum
  • Don't use font weight alone to convey meaning — pair with color, icons, or explicit labels
  • Avoid ALL CAPS for long text — harder to read and screen readers may spell out letter-by-letter
  • Monospace for code/data only: Source Code Pro for technical content, part numbers, code snippets
  • Responsive scaling: Use rem units for font sizes so text respects user's browser zoom settings
