ACCESSIBILITY & BEST PRACTICES

WCAG compliance and implementation guidance for inclusive neutral usage.
  • Body text minimum: Neutral 700 (#4A4A4A) on white meets WCAG AA at 8.7:1 — primary text default
  • Neutral 500 (#777777) is the floor for body text on white (4.6:1) — only use for secondary copy and metadata, never for primary content
  • Don't use Neutral 400 (#949494) for text on white (3.1:1) — fails WCAG AA for body; reserve for placeholders, decorative icons, or disabled states
  • Border colors (200 #DCDCDC, 300 #CCCCCC) are below text contrast minimums — never use for foreground content
  • Disabled state contrast is exempt from WCAG AA, but maintain 3:1 against the background so users can still see disabled controls exist
  • Surface hierarchy: Neutral 0 → 50 → 100 creates depth without shadows — keep contrast steps to 3:1 minimum between adjacent surfaces
  • Black (#000000) is reserved for marketing/print — UI uses Neutral 700 (#4A4A4A) to reduce eye strain on screens
