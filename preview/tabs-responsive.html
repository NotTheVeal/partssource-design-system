Design System / Tabs / Responsive

Tabs — Responsive

1-for-1 match to the Figma Tabs symbol (node 3746:10859 / Property 1=Active & Inactive). 38 px tall, 20 px horizontal padding, 1 px PS Blue border around the active tab — nothing else. Count badge is an 18 × 18 round chip in #DCDCDC with 12 px bold black numerals. Below 480 cq the count badges drop; below 360 cq padding tightens further. Each frame is its own CSS container, so the strip responds to its parent width — not the viewport.

Folder · Page-level sub-nav

Active tab carries a 1 px PS Blue border on all four sides — no top accent, no folder-lift. Inactive tabs are borderless. Panel below picks up the 0 -1px 5px rgba(0,0,0,.15) shadow that anchors it to the tab row.
