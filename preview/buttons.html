Design System / Buttons

Buttons

All button variants and their interaction states. The primary button is a 50px blue outline that fills on hover — per current brand direction (orange fails ADA contrast, so it is being retired from CTAs). The orange pill remains documented below for legacy contexts only.

Primary — Large · 50px

Default button for forms, primary page actions, and modals.
Default
White fill with PS Blue border and text.
Hover
Fill shifts to PS Blue — #005BA6 — border swaps to Blue 4 #009CF4, text to white.
Pressed
Midnight fill #004A84 with a 4px drop shadow — rgba(0,0,0,.25) — on click.
Focus
Default state with a 3px Blue-Gray #B0C6D3 focus ring at 91% opacity.
Disabled
Grey 4 fill #DCDCDC, 2px Grey 2 border and label #777777. Cursor becomes not-allowed.

Secondary — Small · 32px

Compact neutral ghost action — white fill with a 1 px Grey 4 border. Use in table rows, filter bars, and dense toolbars. Often paired with icons.
Default
White background, 1 px Grey 4 border — #DCDCDC — with Grey 1 label #4A4A4A. 10px Source Sans Pro Medium. 4 px corner radius.
Hover
Fills with PS Blue — #005BA6 — text turns white, border stays PS Blue.
Pressed
Darkens to #004A84 on click, white text.
Deactivated
Grey 4 fill #DCDCDC, Grey 3 border and label #949494. Cursor becomes not-allowed.
With Icon
Optional trailing icon — typically export, chevron, or action glyph. Icon color matches label.

Tertiary — Large · 40px

Neutral pill action used for secondary affordances inside cards, filter drawers, and toolbar overflows — never competes with the Primary or Pill. Sentence case, 14px label.
Default
Grey 5 fill — #F1F1F1 — with Grey 1 label. Fully-rounded (pill) radius.
Hover
Background deepens to Grey 4 — #DCDCDC.
Pressed
Darkens to #CCCCCC and picks up a 4px drop shadow — rgba(0,0,0,.25).
Focus
Default fill with a 1px PS Blue border and 3px light-blue focus ring.
Disabled
Same grey fill with Grey 3 label. Cursor becomes not-allowed.

Arrow — Back · 28px

Back-navigation affordance. Pairs with breadcrumbs, drawer headers, and detail-page return actions. Transparent at rest; picks up a 4px-radius square background on hover and press.
Default
Transparent background with Grey 1 left-arrow glyph. 28×28 hit area — no border or fill at rest.
Hover
Picks up a Grey 5 fill — #F1F1F1 — with a 4px-radius square background.
Pressed
Square background deepens to Grey 4 — #DCDCDC — on click. Radius stays 4px.

Pill — Large · 48px

Highest-intent action on a page — typically "Add to Cart" or "Propose Quote". Use only one per view. No small size exists.

Accessibility & Best Practices

WCAG compliance, keyboard support, and implementation guidance for inclusive button design.
  • Minimum 44×44px touch target (WCAG 2.5.5) — Small Secondary buttons are 40px height; pad clickable area to 44px minimum
  • Keyboard navigation: Enter and Space both trigger actions; Tab moves focus; arrow keys navigate segmented button groups
  • Focus indicators: 2px PS Blue outline with 2px offset meets WCAG 2.4.11 (3:1 contrast against adjacent colors)
  • Use semantic <button> elements — not divs or spans; ensures proper keyboard support and screen reader announcements
  • Disabled state: Use disabled attribute so screen readers announce "dimmed" or "unavailable"
  • Icon-only buttons need labels: Add aria-label for back arrow and square icon buttons
  • Loading state: Use aria-busy="true" and lock width to prevent layout shift during spinner
  • Contrast ratios: Orange CTAs (#FF9505) fail WCAG AA — migrating to PS Blue (#005BA6) which meets 5.6:1 on white
