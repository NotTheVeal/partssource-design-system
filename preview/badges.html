Accessibility & Best Practices

WCAG compliance and implementation guidance for inclusive badge design.
  • Color + text: Never rely on color alone — badge text must be legible and descriptive
  • Contrast: All badge color pairs meet WCAG AA standards (4.5:1 minimum)
  • Semantic HTML: Use <span> for inline badges, wrap in <div> when part of card metadata
  • Consistent mapping: Status colors should map consistently across the app (blue = in progress, green = complete, red = critical)
  • Concise text: Keep badge labels short (1-3 words max). For counts, use "XX Items" format
  • Hover states: Optional subtle lift (translateY(-1px)) on hover for interactive contexts
  • Screen readers: Ensure badge context is clear from surrounding content or use aria-label if standalone
  • Responsive sizing: Font size and padding should scale appropriately on mobile (minimum 11px text)
