Layout & Grid

Breakpoints, container widths, columns and gutters. The grid is opinionated on purpose — most product screens fit in one of three templates, and every responsive decision is made against the same five breakpoints.

Page templates

The four shapes 90% of PartsSource screens take. Pick one, then compose into it.

App Shell

Top nav + left rail + main content. The default. Used for Marketplace, Pro, Command Center.

Marketing / CMS

Top nav + full-bleed hero + stacked content blocks. No left rail. Used for landing & campaign pages.

Focused Task

Top nav + 760 px centered column. Used for sign-in, single-purpose forms, checkout.

Detail + Rail

Top nav + main + right rail (status, related, actions). Used for PDP, asset detail, order detail.

Responsive principles

How a layout adapts across the breakpoint scale.

xs · 375 4 col

Single column. Left rail collapses to drawer. Tables become card lists. Hero stacks above content.

md · 768 8 col

Two-column grids. Rail still collapsible. Tables show 4–6 columns max; rest behind a "more" disclosure.

xl · 1440 12 col

Full shell. Left rail expanded. Right rail visible for detail screens. Tables show all columns.

Code · how to use

CSS variables are exposed from tokens.css.
/* CSS — use the container token, gutter token, and a responsive grid */
.page {
  max-width: var(--ps-sem-container-default); /* 1280 px */
  margin: 0 auto;
  padding: 0 var(--ps-space-6); /* 24 px gutter */
}

.dashboard-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);   /* xs · sm */
  gap: var(--ps-space-4);
}

@media (min-width: 768px) {
  .dashboard-grid { grid-template-columns: repeat(8, 1fr); gap: var(--ps-space-6); }
}

@media (min-width: 1024px) {
  .dashboard-grid { grid-template-columns: repeat(12, 1fr); }
}
