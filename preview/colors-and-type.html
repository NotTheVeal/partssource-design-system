ACCESSIBILITY & BEST PRACTICES

WCAG compliance and implementation guidance for inclusive color and typography usage.
  • Color Contrast: All text meets WCAG AA standards (4.5:1 for normal text, 3:1 for large text 18px+). Use --ps-fg-primary (#4A4A4A) on white backgrounds.
  • Orange Deprecation: Moving away from orange CTAs (#FF9505) due to ADA non-compliance. Use blue primary (#005BA6) for interactive elements.
  • Semantic Color Usage: Red for errors, green for success, amber for warnings, blue for info. Never rely on color alone—pair with icons or text labels.
  • Type Scale: Minimum 12px for body text, 14px recommended for UI labels. Line-height ≥1.5 for readability.
  • Font Loading: All @font-face declarations use font-display:swap to prevent invisible text during load.
  • Variable Naming: Use semantic tokens (--ps-fg-primary) over primitives (--ps-neutral-700) for themeable, context-aware styling.
  • Link States: Links use --ps-fg-link (#005BA6) with underline on hover. Ensure 3px minimum click target padding.
  • Monospace Usage: Reserve Source Code for code snippets, variable names, and technical values only—never for UI copy.
