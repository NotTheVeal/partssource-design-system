Design System / Breadcrumb

Breadcrumb

The trail that lives above every detail page. Two canonical patterns sourced from Figma: a back-style single-parent breadcrumb (< Back to My Dashboard) for one-level returns, and a trail-style chevron-separated path (My Dashboard > Asset Details) for two or more levels. Both are Source Sans Pro 14 px with PS Blue parent links and Grey 3 grey current segments.

Back-style

Single-parent return. Use on detail pages reached from one specific list (e.g. asset detail under a dashboard).
Back to My Dashboard

Trail-style

Chevron-separated path. Use when there are two or more parent levels.

Do & Don't

Do
  • Use on detail pages reached from a list.
  • Reflect the user's actual path, not the IA.
  • Truncate long middle segments to "…" when needed.
  • Make every parent a real link.
Don't
  • Add a breadcrumb to top-level pages (no parent).
  • Make the current page a link.
  • Show more than 4 segments — truncate the middle.
  • Use as primary navigation. Use the left rail.
