ACCESSIBILITY & BEST PRACTICES

WCAG compliance and implementation guidance for inclusive color usage.
  • Never use color alone to convey meaning — always pair with text, icons, or patterns (WCAG 1.4.1)
  • Contrast ratios: Text on colored backgrounds must meet 4.5:1 (small text) or 3:1 (large 18px+/14px+ bold)
  • UI component contrast: Interactive elements (buttons, inputs) need 3:1 contrast against adjacent colors (WCAG 1.4.11)
  • Orange CTAs are deprecated — not ADA compliant; use blue outline buttons for primary actions
  • Test with color blindness simulators — red/green confusion is most common (8% of men)
  • Status colors: Success (green), error (red), warning (orange), info (blue) must be paired with icons and labels
  • Link color: PS Blue (#005BA6) meets WCAG AA on white; underline on hover provides additional affordance
