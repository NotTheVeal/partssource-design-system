Bloomreach CMS Components

Content management components for Bloomreach Experience Manager. These components are designed to work seamlessly with the PartsSource design system while providing flexible content authoring capabilities.

Banner

Responsive full-width banner with background image support. Use for page heroes, promotional sections, and campaign headers.

  • backgroundImage: string — URL to background image
  • height: number — Banner height in pixels (default: 93px)
  • overlay: boolean — Dark overlay for text readability
  • alignment: "left" | "center" | "right" — Content alignment

ImageBlock

Two-column layout pairing imagery with rich text content. Supports image placement on left or right, configurable CTA buttons, and responsive stacking on mobile.

  • imageUrl: string — URL to feature image
  • imageAlt: string — Alt text for accessibility
  • imagePosition: "left" | "right" — Image placement (default: "left")
  • title: string — Block heading text
  • content: string — Rich text body content
  • ctaText: string — Call-to-action button label
  • ctaUrl: string — CTA destination URL

TextBlock

Full-width or constrained text content with rich formatting support. Ideal for policy pages, about sections, and detailed product information.

  • content: string — Rich HTML content
  • maxWidth: number — Content max-width in pixels (default: 860px)
  • alignment: "left" | "center" — Text alignment
  • padding: "none" | "sm" | "md" | "lg" — Vertical padding preset

CardGrid

Configurable grid layout for showcasing features, benefits, or products. Responsive columns adapt from 3-col desktop to single-column mobile.

  • cards: Array — Collection of card objects with image, title, content
  • columns: 2 | 3 | 4 — Desktop column count (default: 3)
  • gap: "sm" | "md" | "lg" — Spacing between cards
  • cardStyle: "outlined" | "elevated" — Card visual style

Accessibility & Best Practices

WCAG compliance and implementation guidance for CMS components.
  • Semantic HTML: All components use proper heading hierarchy (<h1> → <h2> → <h3>) for screen reader navigation
  • Image alt text is required: Content authors must provide descriptive alt text for all images — no decorative images allowed in CMS components
  • Keyboard navigation: All interactive elements (buttons, links) are keyboard accessible with visible focus states
  • Color contrast: All text meets WCAG AA standards (4.5:1 for body, 3:1 for large text 18px+)
  • Responsive images: All image components use srcset for responsive loading and proper sizing
  • Link purpose: CTA button text must clearly describe destination — avoid generic "Click Here" or "Learn More" without context
  • Touch targets: All clickable cards and buttons meet 44×44px minimum touch target size (WCAG 2.5.5)
  • Content structure: Use TextBlock for long-form content; ImageBlock for feature highlights; CardGrid for scannable benefits

Technical Implementation

Usage notes and integration guidance for developers.

Component Source

All Bloomreach CMS components are available in the @partssource/react-ui-core package. Import from /cms-components path.

Usage Example

import { ImageBlock } from '@partssource/react-ui-core/cms-components';

<ImageBlock
  imageUrl="/assets/hero.jpg"
  imageAlt="Medical equipment warehouse"
  imagePosition="right"
  title="Mission-critical uptime, on-demand"
  content="<p>Access real-time inventory...</p>"
  ctaText="Request a Quote"
  ctaUrl="/quote"
/>
