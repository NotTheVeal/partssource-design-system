Design System / Tabs

Tabs

Tabs let users switch between sibling views that share context. PartsSource uses three variants — Folder tabs (page-level views, the default), Segmented tabs (compact in-card switching, two–three options), and Pill tabs (filter-style multi-category navigation). All three are sourced from the Figma Tabs symbol family.

Folder · Default

The active tab lifts above the page divider with a 3 px brand-blue top border, 1 px gray side borders, and an open bottom that flows into the panel. Inactive tabs sit borderless on the divider line. 16 px Source Sans Pro, 24 px side padding. Use for page-level sub-navigation.
Active panel content sits flush under the active tab. The divider line breaks under the active tab so the folder shape reads as continuous with the panel.

Segmented · View toggle

Compact icon-only switcher for 2–3 view modes of the same data — Asset uptime, Heatmap, List. 36 px tall, single rounded container with internal 1 px dividers. Active half = white, inactive = #F4F6F8. Pair with a gray View: label so the control reads as a setting, not navigation.
View:
Switch between Asset uptime, Heatmap, and List views without losing your filters, sort, or selection. Each icon button carries a tooltip and an aria-label.

Pill

Filter-style category switcher. 30 px tall, fully rounded. Active pill takes solid brand fill. Use for many sibling categories where users want to feel they’re narrowing a list (parts categories, departments, status filters).

Accessibility

Tabs are one of the most under-implemented ARIA patterns. Get the keyboard + roles right.

Roles

Container is role="tablist". Each tab is role="tab" with aria-selected="true|false". Each panel is role="tabpanel" and references its tab via aria-labelledby.

Keyboard

← → move between tabs and activate the new one automatically. Home / End jump to first / last tab. Tab moves focus into the active panel, never to inactive tabs.

Contrast

Active #005BA6 on #FFF = 7.4:1 (AAA). Idle #000 = 21:1. Disabled #BBB = 2.85:1 — this fails normal-text AA, which is intentional: disabled tabs must look disabled.

Hit targets

Folder tab is 46 px tall active / 40 px idle — meets the 44 px target with 24 px horizontal padding. Pill tabs at 30 px need wider padding (min 14 px) so the effective tap zone is ≥ 44 px.

Selection vs activation

Default to automatic activation — arrow keys both move focus and load the panel. Only use manual activation (arrow keys move focus, Enter activates) if panel loading is slow or destructive.

Don’t hide via icon-only

Segmented view-toggles are icon-only by design — the leading View: label tells users what the control does, and each icon button has an aria-label ("Cards", "Table") for screen readers. If you have > 3 view modes, drop the rare ones into an overflow menu.

Do & Don’t

Picking the right variant prevents 80% of tab problems.

Do

  • Use folder tabs for sibling views of the same data (My Lists / Company Lists / Shared).
  • Keep tab labels short (1–3 words). Long labels squeeze the bar and weaken the folder silhouette.
  • Show counts on the badge when they help orient the user (“47 lists”).
  • Persist active tab in the URL so deep links work and back-button feels native.
  • Keep the active tab one click away — never gate the panel behind a click on a sub-tab.

Don’t

  • Nest tabs. A tab inside a tab inside a tab is always a routing problem dressed up as UI.
  • Use tabs when the views aren’t siblings — that’s navigation, use the sidebar.
  • Use a segmented control for > 3 options. Switch to folder tabs or a select.
  • Use pill tabs for single-select primary views — pills read as filter chips.
  • Hide content in inactive tabs that the user needs to compare. Use side-by-side instead.

When to use what

Three patterns, three jobs. Pick by the relationship between the views, not by how many there are.
Folder

Page-level siblings

Switch between top-level views of the same domain. My Lists / Company Lists / Shared. Cart / Saved / History. 3–6 tabs maximum.

Segmented

View mode switcher

Same data, different layout. Cards / Table. Day / Week / Month. 2–3 icon-only options paired with a View: label.

Pill

Filter-style narrow-down

Many sibling categories where one is the “All” reset. Imaging / Surgical / Lab / IV Therapy. Reads as “narrowing” rather than “switching.”

Sidebar (not here)

Cross-section navigation

If the views don’t share data (Cart vs. Settings vs. Reports), it’s navigation — use the left-hand sidebar, not tabs.
