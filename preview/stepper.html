Design System / Stepper

Stepper

Communicates progress through a multi-step flow — quote request, onboarding, return RMA. From Figma node 396:1813 with three step states (Complete, Current, Pending) plus error and disabled. Numbered circles join with a 2 px track that fills in PS Blue as the user advances.

Horizontal

Default for top-of-page progress bars. Each step is a numbered circle with a label below.
  1. Part selection
  2. Vendor & shipping
  3. 3 Review
  4. 4 Submit

Vertical

Sidebar / drawer pattern. Step label sits to the right of the circle; track runs down the left.

Compact

Dots only, no labels. Use inside cards or dense toolbars when the steps are self-evident.

Accessibility

ARIA pattern + keyboard interaction.
  • Container is an <ol> with an aria-label describing the flow.
  • Current step carries aria-current="step"; complete steps carry no special attr (their checkmark conveys state).
  • Steps that are clickable (e.g. backtrack to a complete step) use the stp__item--button modifier and become <button> elements.
  • Color is never the sole signal — every state pairs with an icon, label, or text change.
  • Error state must be paired with a descriptive sub-label or inline alert beneath the form ("Fix the address before continuing.").
  • Compact dot variant adds a visually hidden label ("Step 3 of 5") for screen readers.
