Design System / Filter

Filter

A multi-faceted filter pattern. Built around a 69px-tall bar with an icon cell on the left, an "Add a Filter" dropdown that expands inline, and a dynamic input area on the right whose contents change to match whichever facet is currently selected (free-form text, comma-separated values, date pickers, range inputs, multi-select chips, etc.). Applied filters render as Brand-Light pill chips on the row below; the row also hosts the "Clear all" and "Save Filer Set" actions. Saved sets persist as named cards with their own apply / edit / delete affordances. Based on the 1440px breakpoint; bar width is dynamic up to 960px.

Behavior

Multi-select rules and apply / reset behavior, paraphrased from the Figma documentation.
  • Multi-faceted filter: selecting an item in the dropdown updates the area to the right with that facet's input controls.
  • Comma-separated entries: users can type multiple values for a single facet (e.g. three facilities) separated by commas.
  • Apply on Enter: pressing Enter commits the active facet and renders chips below the bar.
  • Reset: "Clear all" wipes every chip; individual chips can be removed via their ⊗ glyph.
  • Saved Filter Set name: max 13 characters; longer names truncate with an ellipsis.
  • Save Filter Set modal: uses the current orange pill button component — slated to update once the global pill component changes.
