Accessibility

Keyboard, screen reader, and date-input fallback.
  • Each field is a real <input> with an aria-label ("Start Date" / "End Date") for screen readers.
  • Calendar opens with Enter / Space on the trigger; closes with Esc.
  • Arrow keys navigate days; Page Up / Down moves by month.
  • Today carries aria-current="date"; selected range carries aria-selected="true".
  • Direct typing accepted in MM/DD/YYYY; invalid input triggers the error state instead of silently rejecting.
  • Orange trigger background must always be paired with white icon (3.7:1 contrast — AA Large) — it never carries text.
