Accessibility & Best Practices

WCAG compliance and implementation guidance for inclusive icon design.
  • Icons are decorative by default: Add aria-hidden="true" to icons paired with visible text labels
  • Standalone icons need labels: Use aria-label on the parent button/link (e.g., <button aria-label="Search">)
  • Minimum size 24×24px for standalone interactive icons to meet touch target guidelines (WCAG 2.5.5)
  • Stroke weight consistency: Use 2px stroke across all icons at 24px size; scale proportionally for larger sizes
  • Color contrast: Icons must meet 3:1 contrast ratio against background (WCAG 1.4.11 for UI components)
  • Don't rely on color alone: Pair color-coded icons with text, shape, or position to convey meaning
  • Avoid icon-only navigation: Always pair navigation icons with text labels for clarity
