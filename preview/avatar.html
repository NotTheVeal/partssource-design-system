Design System / Avatar

Avatar

A circular identity marker — photo, initials, or organization mark. Used in the left-hand nav header, comment threads, requester rows, approvals and any list of people. Initials are derived from the first letter of the first and last name; never invent them.

Sizes

Five sizes. md (40 px) is the default for content rows; xs (24 px) matches the LHN header.
EGxs · 24
EGsm · 32
EGmd · 40
EGlg · 56
EGxl · 80

Variants

Photo, initials with a tone-tinted fill, or the brand inverse used in the LHN.

Tokens

Color tone is derived deterministically from the initial. Use the same hash function across the product so a user always renders the same color.
