Design System / Left Hand Navigation

Left Hand Navigation

Vertical primary navigation rail used across PartsSource PRO surfaces. Renders in two widths — an expanded 199 px state with icon + label, and a collapsed 70 px icon-only rail. Both share the same item structure, active state, and color system. The icons below are the canonical glyph set used by the rail; sub-menus reuse them in the back-link header so users can confirm where they are.

Anatomy

Structural breakdown, top to bottom.
  • Profile header (60 px): 23 px white circular avatar with user initials in PS Blue, alongside first name + last initial in 18 px Source Sans white. Background #004A84, drop shadow 0 4px 4px rgba(0,0,0,0.25).
  • Rail body: #003763 background — slightly darker than the header — separates header from the nav list visually.
  • Nav items (40 px tall): 11 px outer padding, 10 px inner padding, 7 px gap between 18 px icon and 14 px label. 3 px corner radius. Items with sub-navigation show a right-aligned chevron.
  • Divider: 1 px PS Blue (#005BA6) inset 12 px on either side — separates utility actions (Logout) from primary navigation.
  • Collapse handle: 30 px PS Blue circle, bottom-right, holding a left-arrow-with-bar glyph. Toggles to the 70 px collapsed width.

Accessibility & Best Practices

WCAG compliance, keyboard support, and implementation guidance for the navigation rail.
  • Landmark role: Wrap the rail in <nav aria-label="Primary navigation"> so screen readers can jump to it directly.
  • Keyboard navigation: Each item is a <button> or <a> reachable via Tab. Enter / Space activates; Arrow Up / Down can optionally cycle between items in the same group.
  • Active page: Mark the current location with aria-current="page" — color alone is not sufficient.
  • Sub-navigation: Items with children must use aria-expanded and aria-controls on the trigger; chevron rotation alone does not meet AT requirements.
  • Color contrast: White text on #003763 rail measures 11.2 : 1 (passes WCAG AAA). Active state white-on-#005BA6 measures 6.4 : 1 (passes AA Large + AA Normal).
  • Focus indicator: 2 px #B6D5F0 outline with 2 px offset on every focusable item. Never outline: none.
  • Touch targets: Item rows are 40 px tall × 177 px wide (expanded) or 32 × 32 px (collapsed). Combined with 19 px rail padding, collapsed items meet the 44 × 44 px minimum (WCAG 2.5.5).
  • Icon-only state: When collapsed, every item must expose its label via aria-label or title; tooltips appear on hover and focus, not hover only.
  • Skip link: Provide "Skip to main content" at the top of every page so keyboard users can bypass the rail.
  • Production sizing: In real layouts the rail is dynamic — it stretches to fill the viewport height. Apply .lhn-expanded--full to the .lhn-expanded element to opt in: the rail becomes height:100dvh with position:sticky; top:0, the item list scrolls internally with a thin custom scrollbar, and the collapse / expand circle is pinned position:sticky; bottom:18px so it always sits above the fold regardless of how many items are in the list. The static sub-rails on this page (Parts Center, Service Center, Tools) use a fixed pixel height purely so all four states can be displayed side-by-side as a spec — that height does not ship to production.

Hamburger Menu · Tablet & Mobile

On Tablet and Mobile the primary navigation collapses behind a hamburger trigger. Tapping it slides this drawer in from the left and dims the page behind with a 45 % black scrim. The drawer mirrors the desktop LHN's structure but reorders rows and drops Asset Uptime & Admin for the smaller surface.

  • Trigger: the hamburger icon in the top-left of the Tablet/Mobile top bar.
