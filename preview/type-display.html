Accessibility & Best Practices

WCAG compliance and implementation guidance for inclusive display typography.
  • Semantic HTML: Use proper heading hierarchy (<h1> → <h2> → <h3>) — screen readers rely on structure for navigation
  • Don't skip heading levels — going h1 → h3 confuses assistive technology and users who navigate by headings
  • Large text contrast: 3:1 minimum (WCAG AA) for text 18px+ or 14px+ bold — lower threshold than body text
  • Tight line-height (1.1-1.2) acceptable for display type, but increase to 1.5 if text wraps multiple lines
  • Avoid light weights (200-300) on small screens — thin strokes are harder to read, especially on low-DPI displays
  • Condensed for space-constrained layouts only — normal width is more legible for long headings
  • Use weight to establish hierarchy, not just size — bolder weights create clearer visual structure
