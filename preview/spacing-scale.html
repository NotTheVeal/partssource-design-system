Accessibility & Best Practices

WCAG compliance and implementation guidance for inclusive spacing design.
  • Touch target spacing: Minimum 8px between interactive elements (WCAG 2.5.5) — prevents accidental taps
  • Text spacing: Line-height minimum 1.5×, paragraph spacing minimum 2×, word spacing minimum 0.16× (WCAG 1.4.12)
  • Consistent spacing creates rhythm — use scale multiples (8px, 16px, 24px) rather than arbitrary values
  • Dense layouts need more spacing — increase padding/margins in data-heavy interfaces for breathing room
  • Mobile: favor larger spacing — touch targets are less precise, need more generous padding than desktop
  • Use rem for scalable spacing — respects user's browser zoom settings better than fixed px values
