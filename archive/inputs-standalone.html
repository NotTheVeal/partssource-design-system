Accessibility & Best Practices

WCAG compliance, keyboard support, and implementation guidance for inclusive form design.
  • Minimum 48px height for all inputs to meet touch target guidelines (WCAG 2.5.5)
  • Floating labels: Label must remain visible when input has value — floats to top at 12px, never disappears
  • Focus indicators: Blue border (10px blur shadow) provides clear keyboard focus state that meets WCAG AA contrast
  • Error states: Red border + error message below input — use aria-describedby to associate error text with input
  • Required fields: Mark with asterisk (*) in label AND use aria-required="true"
  • Disabled inputs: Use disabled attribute (not just visual styling) so screen readers announce the state
  • Dropdown keyboard navigation: Arrow keys navigate items, Enter selects, Escape closes menu
  • Placeholder text: Use sparingly — should supplement label, not replace it (low contrast makes it inaccessible)
