Accessibility Guidelines

WCAG AA compliance standards for inclusive design.

Core Requirements

Guideline Standard PartsSource Implementation
Touch Targets 44×44px minimum (WCAG 2.5.5) All buttons 40px+ height; inputs 48px+
Text Contrast 4.5:1 body, 3:1 large text Body text #4A4A4A on white = 9.4:1
Focus Indicators Visible keyboard focus Blue glow 10px blur, 50% opacity
Line Height 1.5 minimum (WCAG 1.4.12) Body text 1.5, headings 1.2
Font Size 16px minimum for body 16px body, 12px captions minimum

Semantic HTML

  • Use <button> for all clickable actions, not <div> or <span>
  • Use proper heading hierarchy (<h1> → <h2> → <h3>)
  • Use <label> with for attribute for all form inputs
  • Use aria-label for icon-only buttons
  • Use aria-describedby to associate error messages with inputs
  • Use disabled attribute for disabled states (not just visual styling)

Color & Contrast

  • Never use color alone to convey meaning — pair with icons, text, or patterns
  • Ensure sufficient contrast between text and background (4.5:1 minimum)
  • Test with color blindness simulators
  • Orange CTA buttons are being phased out due to insufficient contrast
