Logo

The PartsSource wordmark in three official colorways: blue (primary), white (reversed), and black (single-color print only).

PS Blue Wordmark

Use on white, subtle grey (#FAFAFA), and muted grey (#F1F1F1) backgrounds.

PartsSource

White Wordmark

Use on PS Blue, Midnight, black, and dark imagery.

PartsSource

Logo Usage Guidelines

  • Clearspace: Reserve space equal to cap-height of "P" on all sides
  • Minimum size: 160px width for full wordmark
  • Black wordmark: Use only for single-color print
  • Clickable logos: Wrap in <a> with aria-label="Go to homepage"

Icons

Full Lucide icon set with 1.75px stroke weight. Default color is Midnight (#002F48) for light backgrounds, white for dark.

Icon Guidelines

  • Default stroke: 1.75px for all icons
  • Sizes: 16px, 20px, 24px (default), 32px
  • Accessibility: Use aria-label or aria-hidden="true" + visible text
  • Interactive icons: Minimum 44×44px touch target

Buttons

Primary Button (Large)

325×50px • 2px border • 4px radius • Outline default, filled on hover

Small Button

87×32px • 1px border • 4px radius • 10px text

Orange Pill CTA

48px height • 100px radius • Orange fill • Uppercase

Button Best Practices

  • Minimum 44×44px touch target (WCAG 2.5.5)
  • Use semantic <button> elements for actions
  • Disabled state: Use disabled attribute
  • Focus indicators: Blue outline for keyboard users

Input Fields

Standard Input (40px)

40px height • 1.5px border • Orange hover • Blue focus glow

Input Field Guidelines

  • Always pair with <label> using for= attribute
  • Placeholder is not a label — provide visible label
  • Error state: Red border + error message 11px below
  • Minimum contrast: 4.5:1 for input text

Checkboxes & Radio Buttons

Checkboxes

24×24px • 2px corner radius • Orange fill when selected

Radio Buttons

24×24px circular • 10px inner circle when selected

Selection Controls Best Practices

  • Minimum 44×44px touch target — make label clickable
  • Use checkboxes for multi-select, radio for single-select
  • Group with <fieldset> + <legend>
  • Arrange vertically when possible

Badges

Status Badges

Delivered In Transit Urgent Critical

4px 8px padding • 4px radius • 12px text • 1px border

Badge Guidelines

  • Color + text: Never rely on color alone
  • Contrast: All badge pairs meet WCAG AA
  • Consistent mapping: Blue = progress, Green = complete, Red = critical

Alerts

Alert Banners

Alert Best Practices

  • Use role="alert" for critical alerts
  • Icons are decorative: Add aria-hidden="true"
  • Dismissible alerts: Include close button with aria-label
