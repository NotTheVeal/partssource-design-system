Accessibility & Best Practices

WCAG compliance, keyboard support, and implementation guidance for inclusive card design.
  • Interactive cards need keyboard support: Make entire card focusable with tabindex="0" and trigger action on Enter/Space
  • Hover elevation: Cards lift on hover (0 4px 12px shadow) — ensure focus state matches hover for keyboard users
  • Clickable area: If card is clickable, entire surface should be interactive (not just title or button)
  • Images require alt text: Use descriptive alt for product images; alt="" for decorative icons
  • Semantic structure: Use headings (<h3>) for card titles so screen readers can navigate by headings
  • Button vs link: Use <button> for actions (add to cart), <a> for navigation (view details)
  • Status indicators: Color-coded status pills must include text label — never color alone
  • Minimum contrast: All text must meet WCAG AA (4.5:1 for body text, 3:1 for large text 18px+)
